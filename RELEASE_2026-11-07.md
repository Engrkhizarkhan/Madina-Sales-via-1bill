# 7 November 2026 — route services and counter workflow

The ticket page supports date-specific bus-layout changes and an optional vehicle number. Saving the voucher requires the vehicle number. Layout changes preserve occupied-seat safety: release existing bookings before switching to a different seating plan. Daily departures close their own tickets without locking the bus across days or requiring a return action.

Reservations require only passenger name and mobile. Identification, gender, destination, current fare and discount are completed when collecting payment. Reserved seats never produce a ticket or boarding token. Each paid seat gets its own short sequential base-36 reference, e.g. ME-000001. Previously printed ticket references remain valid and unchanged.

Routes & fares manages destinations and per-bus departure choices, destination/class fares, and optional route-specific commission rates. Buses manages names, capacity, seat-class membership and default fixed commission. A rate above zero is enforced by the API; zero permits manual voucher commission. Unsold tickets use current managed fares; existing tickets retain their amounts. A stale quoted fare requires review. Public search includes all services reaching the selected stop, with the same server-side pricing.
